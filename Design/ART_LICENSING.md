# Dungeon Debt — Art Licensing

All art in `web/assets/` is either **CC0** (public domain) or **CC BY 3.0** (free with attribution). No paid license is required to use, modify, or distribute any asset in this project.

Full per-file attribution is recorded in [`web/ATTRIBUTION.md`](../web/ATTRIBUTION.md). That file is the authoritative source of truth; this document is a summary.

---

## License floor (locked R005-1)

Only **CC0** and **CC BY** art may be added to this project. CC BY-SA (copyleft share-alike) and any Non-Commercial (NC) variant are explicitly rejected.

## Attribution (CC BY 3.0 requirement)

The CC BY 3.0 license requires attribution. This is satisfied by:

- `web/ATTRIBUTION.md` — per-file credit with author name, homepage, and icon name
- The in-game **ART CREDITS** link on the Main Menu (wired to `ATTRIBUTION.md`)

No additional attribution is required for the CC0 assets.

---

## Adding new art

Before committing any new asset:

1. Confirm the license is CC0 or CC BY (no SA, no NC variants).
2. Add the file path, author, icon name, and license to `web/ATTRIBUTION.md`.
3. Update the table in this document.

If a new author or source is introduced, add them as a new section in `web/ATTRIBUTION.md`.
